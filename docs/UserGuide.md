# User Guide

Choose an active profile, then open a registered SharePoint item, browse its registered library, paste a same-tenant registered XML link, or (when allowed) upload XML. Raw paste is an advanced, preview-only option by default. Search displayed fields, preview each recovered document locally, optionally download a copy, and save only when the profile permits it. “Saved” means the uploaded file was independently verified.

Use **Clear Current Record** before leaving a sensitive record. A metadata warning means the file itself was verified but some configured columns were not updated.
