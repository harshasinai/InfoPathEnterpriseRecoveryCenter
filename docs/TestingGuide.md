# Testing Guide

Run `npm test`, `npm run typecheck`, `npm run lint`, `npm run build`, `npm run package-solution`, and `npm audit --omit=dev`. Unit fixtures must be synthetic. Live SharePoint testing must cover each source contract; permissions; registered-library containment; binary integrity; duplicate/hash/replacement behavior; verification; metadata warnings; audit redaction/failure policy; throttling; accessibility; responsive layouts; and object-URL cleanup.
