# Adding a New Form Profile

Create configuration—not a parser. Register exact source/destination libraries, limits, allowed outputs/extensions, and a new configuration version. Add field mappings for overview, approval, hidden, masked, and attachment hints. Unknown populated fields remain visible when `AllowGenericFields` is true. Test inactive with synthetic namespaces, repeated fields, no/one/multiple attachments, mismatch, and duplicates; then obtain department approval and activate.
